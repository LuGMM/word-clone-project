#  Collaborative Word Document

A real-time collaborative word processing application that allows multiple users to create, edit, and manage documents together

## Features

* ✍️ Real-time collaborative editing
* 👥 Multi-user presence and live cursors
* 💾 Automatic document saving
* 🔐 User authentication and permissions
